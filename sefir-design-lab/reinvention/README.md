# Sefir — Concept B (Complete Reinvention)

Isolated design-lab landing experience. Does not modify the repo-root baseline.

## Run

```bash
cd sefir-design-lab/reinvention
npm install
npm run dev
```

Preview: **http://localhost:5174/**

## Design direction

**Signal Desk** — architectural communication orchestration. Cool chalk/slate atmosphere, Syne + IBM Plex Sans (Vazirmatn for FA/AR), teal/amber decision lattice as the signature motif. Interactive routing simulation is clearly labeled and never sends to real accounts.

## Scripts

- `npm run dev` — Vite on port 5174
- `npm run build` — production build
- `npm run preview` — preview build
